\# Win11 Web Terminal 💻🌐



> 基于 \*\*Node.js + Windows ConPTY + xterm.js\*\* 的原生轻量 Web 终端一键部署工具。无需 WSL、无需 Docker、不依赖第三方笨重编译环境，一键在浏览器中获得与原生 Windows Terminal 完全一致的命令行体验。



\---



\## 📖 项目背景与作用



在 Windows 办公与运维场景下，直接访问本地终端往往受限于坐席位置，而市面上常见的 Web 终端工具存在以下痛点：

1\. \*\*WSL / Docker 依赖重\*\*：在纯 Windows 办公机上部署 Linux 容器或子系统过于冗杂。

2\. \*\*底层 ConPTY 兼容缺陷\*\*：原生 `ttyd.exe` 在新版 Windows 11 下极易在 WebSocket 握手时闪退；传统 `child\_process.spawn` 管道模式无法支持交互式命令（导致 SSH、密码盲打、Vim 无法正常输入）。

3\. \*\*外部网络依赖\*\*：公共 CDN 经常因内网策略或网络波动导致样式与脚本无法加载。



\*\*本项目通过一个轻量级 `.bat` 脚本，全自动完成依赖安装、ConPTY 绑定、本地资源托管、双向窗口自适应与开机静默运维配置，提供开箱即用的 Web 终端环境。\*\*



\---



\## 🎯 主要用途



\* \*\*局域网跨设备接入\*\*：利用同一局域网下的手机、平板、iPad 或另一台轻薄本，直接通过浏览器访问并操控宿主 Windows 机器。

\* \*\*轻量 SSH 跳板机\*\*：作为办公或家庭网络内网跳板，免去额外客户端，直接在浏览器内通过 `ssh` 登录管理 OpenWrt 软路由、NAS 或 Linux 服务器。

\* \*\*极简办公\*\*：支持将网页添加为 Chrome / Edge 独立无边框应用（PWA），轻量灵活，无任何弹框干扰。



\---



\## ✨ 核心特性



\- \[x] \*\*原生 ConPTY 驱动\*\*：基于 `node-pty` 调用 Windows 11 底层伪终端 API，原生支持 `ssh` 密码盲打、`top` / `htop`、`vim` 及完整 ANSI 彩色显示。

\- \[x] \*\*全屏动态自适应 (Addon-Fit)\*\*：集成 `@xterm/addon-fit`，窗口缩放、分屏或全屏（F11）时，行列尺寸秒级自动同步，告别右侧黑边与文本排版错乱。

\- \[x] \*\*智能剪贴板交互\*\*：

&#x20; - \*\*Ctrl + C\*\*：有选中文字时执行「复制」；无选中文字时执行「中断当前命令 (SIGINT)」。

&#x20; - \*\*Ctrl + V\*\*：无缝粘贴系统剪贴板文本。

&#x20; - \*\*鼠标流支持\*\*：鼠标选中文本\*\*自动复制\*\*，右键点击\*\*智能复制/粘贴\*\*。

\- \[x] \*\*完全脱离外部网络 (Zero CDN)\*\*：所有 `xterm.js` 及 CSS 样式完全由本地服务静态托管，离线可用。

\- \[x] \*\*零窗口后台常驻\*\*：内置 VBScript 静默启动方案，不占用任务栏黑框窗口。

\- \[x] \*\*智能幂等检查\*\*：安装脚本具备自检能力，重复运行秒级跳过安装，直接拉起服务。



\---



\## 🖥️ 运行环境要求



\* \*\*操作系统\*\*：Windows 11 / Windows 10 (建议版本 >= 1809 以支持 ConPTY)

\* \*\*运行环境\*\*：\[Node.js](https://nodejs.org/) (建议 Node.js 18+ 或更高版本，已在 Node.js v24 下验证通过)

\* \*\*网络与权限\*\*：普通用户或管理员权限均可运行

\## 🚀 快速上手



\### 1. 下载脚本

下载仓库中的 \[`install-or-run-web-terminal.bat`](./install-or-run-web-terminal.bat)。



\### 2. 一键运行

双击运行 `install-or-run-web-terminal.bat`：

1\. 脚本将自动检测环境，于 `D:\\web-terminal` 目录完成初始化并安装依赖。

2\. 自动生成服务端代码与后台静默启动/停止脚本。

3\. 自动在桌面创建快捷方式 \*\*`启动Web终端`\*\*。

4\. 自动在后台启动服务并在浏览器中打开 `http://127.0.0.1:7681`。



> \*\*二次启动\*\*：后续只需双击桌面的「启动Web终端」快捷方式，或再次运行该 `.bat`，即可秒级拉起，无需重新下载依赖。

\## 🛠️ 运维与目录说明



默认部署位置为 `D:\\web-terminal`：



| 文件名 | 功能说明 |

| :--- | :--- |

| `server.js` | 核心服务驱动（静态伺服 + WebSocket + ConPTY 适配） |

| `start.vbs` | 后台静默启动脚本（无黑框弹出） |

| `stop.bat` | 一键停止服务脚本（释放端口占用） |



\### 开机自启动设置

1\. 按 `Win + R` 键，输入 `shell:startup` 回车打开 Windows 自启动目录。

2\. 将桌面的 \*\*`启动Web终端`\*\* 快捷方式复制进该文件夹即可。

\## ⚠️ 安全提示



\* 当前默认监听地址为 `0.0.0.0:7681`，无内置身份鉴权机制。

\* \*\*强烈建议\*\*：仅在受信任的家庭内网或办公专网中使用。如需公网访问，\*\*请务必搭配 Tailscale / ZeroTier 虚拟局域网\*\*，或在前置通过 Nginx / Caddy 增加反向代理与 HTTPS / Basic Auth 认证，严禁将该端口直接通过路由器端口映射裸露在公网上。
